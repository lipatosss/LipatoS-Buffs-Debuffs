LipatoS — Баффы и дебаффы 0.6.6
Foundry 14 / dnd5e 6.0.6, правила истощения Legacy 2014.

УСТАНОВКА
Остановить Foundry. Распаковать ZIP в FoundryVTT/Data/modules/
с заменой папки lipatos-buffs-debuffs. Запустить и обновить страницу (Ctrl+F5).

ИСПРАВЛЕНО
- Убрано дополнительное принуждение помехи на бросках: штрафы даёт только D&D5e.
- Голод сохраняется отдельно в flags, а штатное истощение — один ActiveEffect
  с system.type=exhaustion и system.level=1..6.
- Голод 0: только визуальное предупреждение, без механических штрафов.
- Еда после употребления (через Instant Consumables) снимает только голод.
- Повторная обработка одного долгого отдыха блокируется.
- Панель баффов не удаляется перед каждой перерисовкой листа, восстанавливается
  после изменения эффектов, предметов и обновлений интерфейса.
- Сохраняются иконки голода 0–6, подсказки и ПКМ для ГМа на один уровень.

Проверки: последовательность 0–6, еда, независимое истощение, снижение ГМом,
очистка старых эффектов и отсутствие вторичного вмешательства в броски.
Настоящий игровой мир Foundry автоматически не тестировался.
