# LipatoS — Баффы и дебаффы

Модуль для Foundry VTT 14 и системы dnd5e 6.0.6 (Legacy 2014).

Технический ID модуля: `lipatos-buffs-debuffs`.

Автоматическая установка/обновление через ссылку на [module.json](https://raw.githubusercontent.com/lipatosss/LipatoS-Buffs-Debuffs/main/module.json).

Исходники модуля находятся в корне репозитория. Архив релиза содержит папку `lipatos-buffs-debuffs`.


## Вересковая медовуха (0.6.15)

После успешного использования расходуемого предмета с идентификатором `vereskovaya-medovuha` модуль применяет эффект «Вересковое тепло», бросает 1к4+1 и добавляет **одну пустую бутылку** (`pustaya-butylka`) в инвентарь использовавшего персонажа. При наличии бутылок их количество увеличивается на 1; дубликаты строк не создаются.

Шаблон бутылки ищется сначала в предметах мира, затем в инвентаре персонажей и доступных сборниках предметов. При наличии шаблона копируются исходная иконка, описание, цена (2 см), вес (0,5 фунта) и прочие настройки; шаблон не расходуется. Если шаблон отсутствует, создаётся предмет-добыча «Пустая бутылка» с запасной иконкой и выводится предупреждение. Действие на персонаже запускает один модуль: при включённых двух приоритет имеет «Баффы и дебаффы».

## Исправление 0.6.16: использование медовухи

- Убран ненадёжный WeakMap между `dnd5e.preUseActivity` и `dnd5e.postUseActivity`: D&D5e 6.x создаёт разные экземпляры Activity в начале и в конце использования.
- Обработка ведётся по успешному `dnd5e.postUseActivity` и его собственному объекту результата. Повторная доставка одного результата не создаёт второй бросок или бутылку.
- Списание заряда выполняется системой dnd5e; модуль больше не списывает его повторно. Если настройка `autoDestroy` включена, полностью израсходованная одиночная медовуха исчезает, а для стопки из нескольких бутылок уменьшается количество и сбрасывается счётчик зарядов.
- После применения «Верескового тепла» создаётся один предмет `pustaya-butylka` либо увеличивается его количество. При наличии исходного предмета мира сохраняются изображение и характеристики.
